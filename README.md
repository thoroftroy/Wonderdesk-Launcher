# Wonderdesk Launcher for Android

Wonderdesk Launcher is a home screen: your apps, dock, folders, widgets and search. By Rednave.

## Install and set as home

Requires Android 10 or newer (best on Android 13+).

1. Copy the APK file to your phone and tap it. Allow "install from unknown sources" when asked.
2. Press the Home button and choose Wonderdesk when asked which home app to use. To change it later, use the "Default home" button inside the app or Android Settings → Apps → Default apps → Home app.

## Using the Launcher

- The home page holds favorite apps, a clock, folders and widgets; swipe for more pages.
- Open All apps for the full drawer, or type to search installed apps and calculate.
- Long-press any app to add it to home or the dock (up to 10 dock apps), or to file it in a folder.
- Home settings adjusts the grid size, tint and layout; layouts can be exported to a file and restored from one.
- New default layouts include your music player in the dock when it is installed; your existing layout is never rewritten.

Widgets depend on the apps that provide them. The launcher cannot replace the lock screen or notification shade, and there are no icon packs or cross-device sync.

## Look and feel

Open About inside the app to choose between Aqua, Bliss, Dark Bliss and Super, and to adjust motion. Aqua is the default.
